# HushRaster barcode examples

This folder contains **278 PNG barcode examples**, one for every successfully generated implemented standard found in the included source snapshot. All use the same payload:

```text
Hello, World!
```

The final line break is a real line-feed byte (`0x0A`), not the two characters `\` and `n`. Exact payload hex: `48 65 6c 6c 6f 2c 20 57 6f 72 6c 64 21 0a`. All images use **4 pixels per module (ppm 4)**.

## View without installing HushRaster

Open `index.html` in a browser. It provides a searchable gallery; click a barcode for its full-size PNG, or save/share the individual PNG. Recipients do not need HushRaster installed to view the images.

## Verification

Each image was generated by the included CLI and decoded with its explicit selector. Recovered bytes were compared byte-for-byte against the payload. Implemented standards discovered: 278; passed: 278; failed: 0.

All implemented standards generated and round-trip verified.
